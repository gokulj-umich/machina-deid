# machina-deid

Team **Gocool**'s pipeline for the Machina CAD De-ID track (Builders Buildathon, Nov 2026).
It replaces identifying names, accounts, contact details and domains in a large engineering
corpus with consistent pseudonyms while keeping every CAD file, drawing and archive usable.

    bash run.sh 1      # builds ~/work/attempt-1/{corpus,code,README.txt}

See `deid/README_TEMPLATE.txt` for the method and known limitations. MIT licensed.
